# Bloom — Módulo Estudante

Frontend estático do Bloom para demonstração do TCC. Não possui backend, banco de dados ou autenticação real.

## Executar localmente

Abra `index.html` no navegador. Para desenvolvimento local opcional, use qualquer servidor estático.

## GitHub Pages

O projeto foi preparado para publicação como site estático a partir da branch `main` e da pasta raiz. Em GitHub → Settings → Pages, selecione `Deploy from a branch`, branch `main` e folder `/ (root)`.

Depois da publicação, o site ficará disponível no endereço padrão do GitHub Pages deste repositório.

## Conteúdo

- Home
- Organizar
- Estudar
- Bem-estar
- Instituição
- Notificações
- Meu perfil
- Configurações

Todos os dados são mockados e as interações são mantidas no estado do navegador.
